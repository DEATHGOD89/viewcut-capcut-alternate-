# Video Editor Lite

Lightweight professional video editor optimized for performance.

## Requirements

- Python 3.8+
- FFmpeg (must be in PATH)
- Minimum 4GB RAM (8GB recommended)

## Installation

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## Usage

```bash
python src/main.py
```

## Features

- Trim, split, merge video clips
- Audio extraction and volume control
- Color filters (brightness, contrast, warm/cool, sharpness)
- Resolution and aspect ratio conversion
- Speed change and reverse
- Export with quality preservation
